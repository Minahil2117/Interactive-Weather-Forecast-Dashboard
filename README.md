# 🌤️ Interactive Weather Forecast Dashboard

A modern, responsive weather application built with HTML5, CSS3, and ES6+ JavaScript, featuring real-time weather data, location search, 7-day forecasts, and interactive charts powered by Chart.js.

## 🌟 Features

- **🌍 Real-time Weather Data**: Get current weather conditions for any location worldwide
- **🔍 Location Search**: Search for cities with autocomplete functionality
- **📊 7-Day Forecast**: Detailed weekly weather predictions
- **📈 Interactive Charts**: Beautiful temperature and weather trend visualizations using Chart.js
- **📱 Responsive Design**: Optimized for desktop, tablet, and mobile devices
- **🎨 Modern UI**: Clean, intuitive interface built with Tailwind CSS
- **⚡ Fast Performance**: Efficient API calls with caching mechanisms
- **🌗 Dynamic Icons**: Weather condition icons that adapt to current conditions

## 🛠️ Technologies Used

### Frontend
- **HTML5**: Semantic markup and modern web standards
- **CSS3**: Advanced styling with Flexbox and Grid
- **Tailwind CSS**: Utility-first CSS framework for rapid UI development
- **ES6+ JavaScript**: Modern JavaScript with async/await, modules, and arrow functions

### Libraries & APIs
- **Chart.js**: Interactive and responsive charts
- **OpenWeatherMap API**: Real-time weather data
- **Geocoding API**: Location search and coordinates

### Development Tools
- **Git**: Version control
- **VS Code**: Development environment
- **Live Server**: Local development server

### 📖 Usage
- Search for Weather: Enter any city name in the search bar
- View Current Conditions: See temperature, humidity, wind speed, and weather description
- Explore 7-Day Forecast: Scroll through the weekly forecast cards
- Analyze Trends: Interact with charts showing temperature variations
- Switch Locations: Search for different cities without page refresh


### 🔧 API Configuration
- The application uses the following OpenWeatherMap API endpoints:
- Current Weather Data: https://api.openweathermap.org/data/2.5/weather
- 7-Day Forecast: https://api.openweathermap.org/data/2.5/forecast
- Geocoding: https://api.openweathermap.org/geo/1.0/direct
